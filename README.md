## 🔧 Troubleshooting the Tempo

- **“Trainer Doesn’t Detect My Game”** — Ensure the game is running as an administrator. If it still isn’t detected, manually browse to the game’s `.exe` file via the trainer’s “Target Selector” menu.
- **“Sliders Are Grayed Out”** — Run a fresh Silent Scan after any game update. The trainer ships with a “Re-Scan Offsets” button in the settings gear icon.
- **“Overlay Flickers on My Second Monitor”** — Set the overlay to “Borderless Window Lock” mode in the display settings. This restricts the HUD to your primary gaming display only.
